## Goal

Make Vite preview serve a prerendered route's generated directory-index document at the route without a trailing slash. The generated SSG app declares `/about` and links to `/about`, but preview returns Home HTML there because the build emits `about/index.html` and Vite's HTML fallback probes `about.html` before selecting the root document. Resolve existing directory indexes through a private preview middleware in the build plugin, ahead of Vite's fallback. Keep the requested browser URL and generated output layout.
